# Géosciences 1 – Structure de la Terre : le cours expliqué

Site de révision du cours de L1 « Géosciences 1 – Structure de la Terre » (Université de Strasbourg, EOST, 2026-2027), parties d'A.-D. Schmitt (enveloppes superficielles) et de F. Masson (enveloppes internes).

- `index.html` : le site complet, autonome (ouvrir dans un navigateur ou publier avec GitHub Pages).
- `src/` : les morceaux qui servent à assembler `index.html` (sections HTML et banques de questions JS).

Contenu : chaque chapitre expliqué simplement, « à savoir par cœur », QCM par chapitre, exercices d'entraînement corrigés, examens blancs CC1/CC2, QCM au format réel (A-E, plusieurs réponses), annales et ressources d'autres universités.

Document de révision personnel : en cas de doute, le cours des enseignants fait foi.
